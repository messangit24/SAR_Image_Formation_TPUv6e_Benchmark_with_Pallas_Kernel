3. PHYSICAL HARDWARE TOPOLOGY & LATENCY DECOMPOSITION
================================================================================
Hardware Path Breakdown for Single 11.26 GB Scene Ingestion & Formation:
1. GCS FUSE Ingress (3.971 s):
   - Reads 726 MB signal block directly from Google Cloud Storage via VPC.
   - Random seeks are coalesced into single sequential block reads.
2. Host-to-Device PCIe Gen5 DMA (1.4735 s):
   - Streams complex radar vectors from Host DDR5 memory to TPU High Bandwidth Memory (HBM).
3. TPU v6e VPU Kernel Compute (5.111 s for FFBP, 15.721 s for BPA):
   - 16 TPU v6e Trillium chips process 128x128 spatial tiles concurrently.
   - Vector Processing Unit (VPU) performs matched-filter phase rotations.
4. Optical ICI Reduction (<0.005 s):
   - Cross-host sub-aperture all-reduce executed over 1,600 Gbps optical torus.
   - Adds less than 0.05% overhead to total execution latency.
5. Point-Target Quality Verification (0.082 s):
   - Host CPU verifies Peak Sidelobe Ratio (PSLR) and complex coherence.

Micro-Architectural Mechanics:
- 1,024x Write Reduction: Standard JAX BPA evicts intermediate complex pixel sums
  to external HBM per pulse. Pallas keeps partial sums inside 16 MiB on-chip Vector
  SRAM (vMem) across all 1,024 pulses, writing to HBM only upon completion.
- Compute Density: Arithmetic intensity increases 12.7x (3.6 -> 45.7 FLOPs/byte),
  moving the kernel out of memory-bound stagnation into the compute-bound VPU regime.
- Optical ICI Link Saturation: Multi-host sub-aperture merge achieves 1,110.65 Gbps
  (69.4% saturation of the theoretical 1,600 Gbps physical link).
