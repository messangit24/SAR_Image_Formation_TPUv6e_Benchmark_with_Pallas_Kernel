1. TOTAL SIZE OF DATASET PROCESSED
--------------------------------------------------------------------------------
The dataset processed in the Cloud TPU v6e (Trillium) multi-chip benchmark run
breaks down across physical storage, raw collection aperture, and active TPU memory:

A. Raw Umbra Scene Files Downloaded:
   - CPHD phase history:  2023-01-18-07-20-11_UMBRA-05_CPHD.cphd  (610.7 MB)
   - SICD reference file: 2023-01-18-07-20-11_UMBRA-05_SICD.nitf  (66.6 MB)
   - Total scene files downloaded to local storage: ~677.3 MB

B. Full Scene Raw Pulse Aperture:
   - Total radar pulse vectors: 5,320 pulses
   - Samples per pulse vector:  14,999 complex range frequency samples
   - Total full-aperture matrix size:
     5,320 pulses x 14,999 samples x 8 bytes (complex64) = 638,357,440 bytes (~638.4 MB)

C. Ingested Data Slice Processed on Cloud TPU v6e (Trillium):
   - Broadside pulses selected: 512 pulses (centered at zero-Doppler)
   - Frequency samples per pulse: 14,999 complex samples
   - Active raw data matrix ingested into TPU HBM:
     512 pulses x 14,999 samples x 8 bytes = 61,435,904 bytes (~61.4 MB)
   - Processed through 4 backprojection algorithms:
     1. Baseline Standard JAX Cloud TPU BPA (Single-Chip)
     2. Single-Chip Optimized Pallas BPA (Prefetch & Double Buffering)
     3. Multi-Chip Pallas BPA (8-Chip 2x4 mesh spatial parallelism)
     4. Multi-Chip Pallas FFBP (8-Chip 2x4 mesh chunk parallelism)

D. Target Reconstructed Slant-Plane Grid:
   - Reconstructed grid dimensions: 512 x 512 complex pixels
   - Output spatial array size: 262,144 complex64 values (~2.09 MB)

E. Full Umbra Open Catalog Scope (75+ TB Context):
   - The script download_umbra_data.sh points to the sample test scene,
     while the full Umbra Open Data Catalog spans thousands of worldwide
     spotlight and stripmap SAR collects totaling over 75+ Terabytes.
   - For bulk storage beyond Google Cloud's 64 TB persistent disk hard limit,
     an exabyte-scale Cloud Storage bucket was provisioned:
     gs://umbra-sar-dataset-75tb-mb-development-447000 (europe-west4)
     which can be mounted directly into GKE pods using the GCS FUSE CSI driver.


2. WHAT IS THE OUTPUT OF THE INFERENCE? IS IT JUST A PNG FILE?
--------------------------------------------------------------------------------
Answer: NO, the output is DEFINITELY NOT just a PNG file.

A PNG image is only an 8-bit dynamic-range compressed visualization ("quicklook")
generated for human inspection. The core mathematical and scientific output of
the SAR image formation inference is a complex-valued 2D matrix/tensor.

A. Primary Scientific Output: Complex Reflectivity Matrix (I + jQ)
   - Shape: (512, 512), Dtype: numpy.complex64 (or complex128)
   - Each pixel contains both:
     1. Magnitude |z| = sqrt(I^2 + Q^2):
        The physical radar backscatter cross section (RCS / intensity).
     2. Phase phi = atan2(Q, I):
        The high-precision coherent microwave wavefront travel distance.

B. Why PNG Discards Critical SAR Information:
   - PNG images are restricted to 8-bit integers [0 to 255] per channel.
   - Quantizing to PNG completely discards the phase (phi) and compresses
     the 40-60 dB floating-point dynamic range into 256 discrete bins.
   - Downstream radar remote-sensing applications are impossible without
     the complex floating-point output:
     * InSAR (Interferometric SAR): Uses the phase difference between two passes
       to measure millimeter-scale ground displacement, volcanic inflation,
       subsidence, and earthquake fault deformation.
     * Coherent Change Detection (CCD): Leverages complex phase decorrelation
       to detect sub-resolution physical disturbances (e.g., vehicle tracks).
     * Polarimetric Target Classification: Uses complex scattering matrices
       (HH, HV, VH, VV) to decompose surfaces vs. volumetric canopies vs. buildings.

C. Standard Scientific / Operational SAR Product Formats:
   In production SAR pipelines (NGA / NATO STANAG 4545 standards), the complex
   output is packaged into:
   - SICD (Sensor Independent Complex Data, NITF 2.1):
     Standard complex SAR container containing raw complex floating-point
     samples accompanied by full XML physical sensor geometry, antenna gains,
     Earth-Centered Earth-Fixed (ECEF) projections, and calibration polynomials.
   - Cloud-Optimized GeoTIFF (COG):
     Georeferenced float32/complex floating-point rasters for GIS platforms.
   - Raw NumPy / HDF5 / Zarr arrays:
     Used for direct machine learning feature extraction and inference.

D. Ancillary Output Artifacts Generated by the Benchmark:
   1. Complex Image Array:
      Maintained in memory and validated across all 8 TPU chips.
   2. Rendered Quicklooks (PNG):
      Rendered via logarithmic decibel scaling (to_uint8_db, e.g., -40 dB to 0 dB)
      saved in the out/ directory for visual verification.
   3. Quantitative Metric Reports (Markdown / Plaintext):
      Detailed phase coherence (gamma_median = 0.9967), High-Signal Coherence
      (0.9976), Normalized Cross-Correlation (0.9944), and -3dB Impulse Response
      point target resolutions (0.35 m range, 0.35 m azimuth).
