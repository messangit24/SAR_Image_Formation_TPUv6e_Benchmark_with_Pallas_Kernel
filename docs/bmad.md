# BMAD in TPUbench — Planned, Story-Driven Development

[BMAD](https://docs.bmad-method.org/) (Build More, Architect Dreams) is an AI-driven development framework: a set of **persona agents** (Analyst, PM, Architect, Scrum Master, Dev, QA) and **workflow skills** that take a feature from idea → PRD → architecture → sharded stories → implementation → review.

In this repository, BMAD scaffolds the **planning, architecture, and story execution** of non-trivial features for **GoldThread / TPUbench (AGO TO2)**. The repository's own verification gates (SAR coherence, `pytest`, `ruff`, and `terraform` validation) remain the strict **definition of done** (see [`AGENTS.md`](../agents.md)).

## 🚀 How to Use BMAD in this Repo

### 1. Orientation
Whenever you start a session or need to know the next step:
- Run **`bmad-help`** — orients you on the current phase, existing artifacts, and recommends the next skill.

### 2. Feature Sizing & Flow
- **Small / Mechanical Fixes**: Skip BMAD or use `[QQ] bmad-quick-dev`. Implement and run verification gates directly.
- **Medium Features**: Use `[SP] bmad-spec` (concise SPEC.md) → `bmad-dev-story`.
- **Large Features / Subsystems (e.g., New SAR Algorithm or Pipeline Module)**:
  - **Phase 1: Analysis**: `[BP] brainstorming` · `[CB] product-brief` · `[TR] technical-research`
  - **Phase 2: Planning**: `[PRD] create-prd`
  - **Phase 3: Solutioning**: `[CA] architecture` ✱ → `[CE] create-epics-and-stories` ✱ → `[IR] check-implementation-readiness` ✱
  - **Phase 4: Implementation**: `[SP] sprint-planning` ✱ → `[CS] create-story` ✱ → `[DS] dev-story` ✱ → `[CR] code-review`

## 🔗 Linking BMAD Stories to GitHub & TaskFlow

Each BMAD **story** maps to a **GitHub Issue / PR** and a **Buganizer Task** in the **GoldThread TaskFlow Workspace**:

1. **GitHub Issue Bridge** ([`scripts/bmad_gh.py`](../scripts/bmad_gh.py)):
   ```bash
   python scripts/bmad_gh.py docs/bmad/stories/<story-file>.md
   ```
2. **Automated Submission** ([`scripts/bmad_submit.py`](../scripts/bmad_submit.py)):
   - Runs upon story completion.
   - Pushes branch to `origin`.
   - Opens PR on `personal/goldthread` via `ggh`.
   - Creates/updates Buganizer task under Component `2011243` and Hotlist `8806410` (Workspace **6001488**).

## 🛡️ Definition of Done Verification Gates

Inside `bmad-dev-story` and before marking any story as complete, the following gates must pass:
1. `ruff check src tests scripts` → **clean**
2. `pytest -q` → **all green**
3. **SAR Coherence Verification**: FFBP & BPA complex coherence against reference SICD ground truth $>97.0\%$ ($>0.97$).
4. **Terraform Validation**: `terraform fmt -check` and `terraform validate` inside `terraform/`.
5. Update docs and benchmarks in [`docs/PERFORMANCE_BENCHMARKS.md`](PERFORMANCE_BENCHMARKS.md) and [`README.md`](../README.md).
